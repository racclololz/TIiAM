# Tiam

Shows your Windows 11 tray icons on the taskbar of every monitor. They work like the real ones, even while a full-screen game covers your main monitor.

## Install

1. Download [Tiam.exe](https://github.com/racclololz/Tiam/releases/latest/download/Tiam.exe) and open it.
2. If Windows warns you, click **More info**, then **Run anyway**.
3. Open it again and choose **Start with Windows** to keep it after a restart.

## Remove

Open Tiam again, untick **Start with Windows**, then choose **Quit**.

## Good to know

- Needs Windows 11 with **Show my taskbar on all displays** turned on (Settings > Personalization > Taskbar).
- Icons hidden behind the **^** arrow are not shown.
